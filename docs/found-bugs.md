# Bugs found by the characterization tests

The characterization tests in `test/api/characterization/` turned these up. Each one is snapshotted exactly as it behaves today, so a fix will show up as a deliberate snapshot change (`npm run test:api:update`, then review the diff).

Phase 3 of the [SQLite migration plan](sqlite-migration-plan.md) fixes the storage bugs it lists, one commit per bug. Those rows start with **Fixed**, and say which part was fixed when only part was. Every other bug is still there.

The **Evidence** column names the test that pins each bug down: `<file> › <endpoint> › <case>`. Its snapshot is in the matching `*.test.js.snapshot` file.

Severity guide:
- **High:** data loss, or anyone can do anything.
- **Medium:** wrong data gets stored, or a 500 on input a client can easily send.
- **Low:** surprising behaviour, but nothing breaks.
